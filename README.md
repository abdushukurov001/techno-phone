# Texnikalar — Internet Do'koni

Toshkentda tekshirilgan smartfonlar, noutbuklar va gadjetlar do'koni.

## Texnologiyalar

- React 19
- TanStack Start & TanStack Router
- Tailwind CSS 4
- Supabase

## Ishga tushirish (Local Development)

```sh
npm install
npm run dev
```

## Sinovlar (Tests)

```sh
npm run test
```
